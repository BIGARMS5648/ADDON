# BIGARMS

WoW Forever(와우 포에버)용 **통합 편의 애드온**입니다. 커스포지에서 많이 쓰는 편의 애드온들(Leatrix Plus, ForeverPlus, Forever++, GatherMate2, TomTom, Scrap, Postal, OmniCC, RareScanner, BugSack, Prat, TipTac, SexyMap, Pawn의 장비 비교 등)이 하는 일을 **49개 모듈** 하나에 모았습니다. 모듈마다 따로 켜고 끌 수 있습니다.

## 어떤 애드온을 대신하나

| 커스포지 애드온 | BIGARMS 모듈 |
| --- | --- |
| Leatrix Plus (자동화 · 채팅 · 프레임 · 인터페이스) | 자동 수리 · 잡템 판매 · 자동 퀘스트 · 자동 수락 · 자동 거절 · 전장 영혼 해방 · 빠른 줍기 · 채팅 · 툴팁 · 미니맵 · 인터페이스 · 창 이동 · 상인 · 훈련사 · 게임 설정 |
| ForeverPlus / Forever++ | 위 전부 + 버프 알림 · 탄약 경고 · 오류 필터 · 경매장 시세 · 채집 지도 · 나침반 · 비행 타이머 · 오류 수집기 · 이름표 · 우편 |
| GatherMate2 / Gatherer | 채집 지도 (세계 지도 + 미니맵) |
| TomTom | 좌표 길찾기 (`/way`, 화살표, 추적 퀘스트 화살표) |
| Scrap / SellJunk / Vendor Price | 잡템 판매, 툴팁 판매가 |
| Postal | 우편 (받는 사람 버튼) |
| OmniCC | 행동 단축바 (재사용 대기시간 숫자) |
| RareScanner / SilverDragon | 희귀 몹 경보 |
| BugSack / BugGrabber | 오류 수집기 |
| Prat / Chatter | 채팅 (링크, 복사, 기록 복원, 짧은 채널 이름, 링크 툴팁) |
| TipTac | 툴팁 |
| SexyMap | 미니맵 (사각, 좌표, 버튼 모으기) |
| Pawn (장비 비교 부분) | 툴팁 "착용 중" 비교 줄 |
| BetterBlizzPlates (일부) | 이름표 (퀘스트 아이콘, 대상 테두리, 전투 중에만 표시) |
| DBM 풀 타이머 | 풀 타이머 (`/pull`) |
| Altoholic (골드 · 플레이 시간) | 골드 추적 (`/ba alts`) |
| Auto Roll / LootConfirm | 자동 주사위, 전리품 확인 창 |
| CursorTrail | 커서 링 |
| FlightMap 타이머류 | 비행 타이머 |
| Interrupt announcers | 차단 알림 |

Questie(퀘스트 데이터베이스), AtlasLoot(전리품 DB), WeakAuras, Details(피해량 측정기) 같은 **대용량 데이터베이스 · 전투 로그 애드온은 들어 있지 않습니다.** 포에버는 전투 로그를 애드온에 주지 않아서 피해량 측정기는 게임 내장 기능을 써야 합니다.

포에버는 클래식 콘텐츠를 **최신(미드나이트 시대) 클라이언트 API** 위에서 돌립니다. 그래서 이 애드온은 처음부터 포에버 API(`## Interface: 16001`, `C_*` 네임스페이스, 전투 중 비밀 값)에 맞춰 만들었습니다. 클래식 시대용 애드온을 옮겨 온 것이 아닙니다.

## 설치

1. `BIGARMS` 폴더를 통째로 다음 위치에 복사합니다.
   `World of Warcraft\_forever_\Interface\AddOns\BIGARMS`
   (`BIGARMS.toc` 파일이 `AddOns\BIGARMS\` 바로 안에 있어야 합니다.)
2. 게임 접속 후 캐릭터 선택 화면의 **애드온** 목록에서 BIGARMS가 켜져 있는지 확인합니다.
3. `/ba` 로 설정 창을 엽니다. `ESC > 설정 > 애드온 > BIGARMS` 에도 있습니다.

## 모듈

기본값은 ✅ 켜짐 / ⬜ 꺼짐입니다. 꺼져 있는 것은 성격상 호불호가 갈리거나 화면을 차지하는 기능입니다.

### 자동화

| 모듈 | 기본 | 하는 일 |
| --- | --- | --- |
| 자동 수리 | ✅ | 수리 상인을 열면 전부 수리. 길드 자금 사용 옵션. |
| 잡템 판매 | ✅ | 회색 아이템 자동 판매. `/ba junk keep <링크>` 로 예외, `/ba junk add <링크>` 로 항상 판매. |
| 자동 퀘스트 | ✅ | 퀘스트 받기 · 완료, 선택지가 하나뿐인 대화 넘기기. 보상이 여러 개면 **가장 비싸게 팔리는 보상에 금색 테두리**만 표시하고 선택은 직접. Shift(변경 가능)를 누르고 있으면 멈춤. 회색 · 반복 퀘스트는 옵션. `/ba quest block <퀘스트ID>` 로 제외. |
| 자동 수락 | ✅ | 친구 · 길드원의 파티 초대(모두 허용 가능), 부활(전투 중 제외), 소환(지연 시간 설정). |
| 자동 거절 | ✅ | 결투(기본), 길드 초대 · 창설 서명 · 거래(옵션). 친구와 길드원은 예외. |
| 전장 자동 영혼 해방 | ✅ | 전장에서 죽으면 바로 해방. 자기 부활 수단이 있으면 안 함. |
| 빠른 줍기 | ✅ | 전리품 창이 열리는 즉시 모두 줍기 (자동 줍기 설정과 연동). |
| 쉬운 삭제 | ✅ | 아이템 파괴 확인 창에 DELETE 자동 입력. |
| 영상 건너뛰기 | ⬜ | 시네마틱 · 동영상 건너뛰기. 키를 누르고 있으면 봄. |
| 추적 유지 | ✅ | 약초 찾기 / 광물 찾기를 죽은 뒤, 지역 이동 뒤에 다시 켬. |
| 자동 일어서기 / 내리기 | ✅ | "앉아 있을 수 없습니다", "탈것 위에서는…" 오류가 뜨면 알아서 처리. |
| 자동 스크린샷 | ⬜ | 레벨 업 때 스크린샷. |

### 툴팁

위치, 전투 중 숨기기(Shift로 보기), 크기, 이름 직업 색, 직업 · 반응 색 테두리, 길드 계급, 대상의 대상, 생명력 바 숨기기, 아이템 레벨, **착용 중인 장비와 비교("착용 중: 23 (+7)")**, **마지막으로 본 경매장 시세**, 판매가(묶음 전체), 보유 개수(가방 / 은행), 등급 색 테두리, 아이템 ID, 주문 ID.

### 미니맵

사각 미니맵, 지역 이름 · 시계 · 달력 · 확대 버튼 · 추적 버튼 숨기기, **좌표**, 자동 축소, 핑한 사람 알림, 다른 애드온 버튼 모으기. 미니맵 버튼 위에서 휠을 굴리면 **전체 음량** 조절.

## 명령어

| 명령 | 설명 |
| --- | --- |
| `/ba` (`/bigarms`, `/빅암즈`) | 설정 열기 |
| `/ba list` | 모듈 목록과 상태 |
| `/ba on <모듈>`, `/ba off <모듈>`, `/ba toggle <모듈>` | 모듈 켜기 / 끄기 (예: `/ba off AutoQuest`) |
| `/ba set <모듈> <옵션> <값>` | 옵션 값 바꾸기 (예: `/ba set Durability threshold 30`). 옵션 이름을 틀리면 목록을 보여 줍니다. |
| `/ba junk add\|del\|keep\|unkeep <아이템 링크>`, `/ba junk list` | 잡템 판매 예외 목록 |
| `/ba quest block\|unblock <퀘스트ID>` | 자동 퀘스트 제외 |
| `/way x y [메모]`, `/way clear` | 좌표 길찾기 (`/좌표`, `/ba way` 도 됨) |
| `/ba gold`, `/ba xp`, `/ba dura` | 골드 · 경험치 · 내구도 보고 |
| `/ba alts`, `/ba session` | 전체 캐릭터 목록, 이번 접속 요약 |
| `/pull [초]` (`/ba pull`) | 풀 타이머. `/pull 0` 취소 |
| `/ba buffs add\|del <주문 이름>` | 버프 알림 감시 목록 |
| `/ba ah <아이템 링크>` | 기억한 경매장 시세 |
| `/ba nodes`, `/ba nodes clear` | 채집 위치 개수 / 삭제 |
| `/ba errors`, `/ba errors clear` | 잡은 Lua 오류 창 / 삭제 |
| `/ba volume [0-100]`, `/ba home`, `/ba cvar <이름> [값]` | 음량, 귀환 장소, 게임 설정 보기 · 바꾸기 |
| `/ba copy` | 채팅 복사 창 |
| `/ba frames reset` | 옮긴 창 위치 초기화 |
| `/ba minimap` | 미니맵 버튼 보이기 / 숨기기 |
| `/ba reset` | 전체 초기화 |
| `/rl`, `/clear` | UI 재시작, 채팅 지우기 (다른 애드온이 이미 쓰면 양보) |

미니맵 버튼: 좌클릭 설정, 우클릭 골드 · 경험치 보고, 휠 클릭 채팅 복사, 휠 굴리기 음량, 드래그로 이동. 툴팁에 골드 · 경험치 · 내구도 · 귀환 장소 · 음량 · 오류 수가 나옵니다. 미니맵 옆 **애드온 목록 버튼**에도 들어 있습니다.

**키 설정** (ESC > 키 설정 > BIGARMS): 설정 열기, 채팅 복사, 풀 타이머, 좌표 지우기, 오류 창, 미니맵 버튼.

## 알아 둘 점

- **전투 중 비밀 값**: 포에버(미드나이트 엔진)는 전투 중 생명력 · 오라 · 재사용 대기시간 같은 값을 애드온에 숨깁니다. BIGARMS는 그런 값으로 판단하는 기능을 넣지 않았고, 비밀 값이 넘어오면 조용히 건너뜁니다. 그래서 전투 중 체력 경고 같은 기능은 없습니다.
- **모듈 하나가 고장 나도** 나머지는 돌아갑니다. 모듈의 이벤트 처리는 각각 보호되어 있고, 오류는 모듈 이름과 함께 채팅창에 한 번만 표시됩니다. 그 내용을 알려 주시면 고칠 수 있습니다.
- 클라이언트가 모르는 이벤트 · 창 · 함수는 모두 **있는지 확인한 뒤** 씁니다. 포에버 빌드가 바뀌어 어떤 창 이름이 달라지면 그 기능만 조용히 비활성화됩니다.
- 커스포지는 이 개발 환경에서 직접 열 수 없어서, 애드온 목록과 기능은 검색 결과와 각 애드온의 공개 저장소 · 문서를 바탕으로 정리했습니다.
- 일부 모듈(채팅, 툴팁, 미니맵, 인터페이스, 아이템, 퀘스트, 창 이동, 행동 단축바)은 블리자드 UI에 훅을 걸기 때문에, 끄면 **`/reload` 해야 완전히 원래대로** 돌아갑니다. 끌 때 안내 문구가 나옵니다.
- 자동 퀘스트는 **보상을 대신 고르지 않습니다.** 보상이 둘 이상이면 가장 비싸게 팔리는 것에 테두리만 표시합니다.
- 설정은 계정 공용(`BIGARMSDB`)이고, 잡템 예외 · 퀘스트 제외 · 좌표 · 채팅 기록은 캐릭터별(`BIGARMSCharDB`)입니다.
- Twinkle(반짝이)과 같이 쓰면 퀘스트 오브젝트 반짝이는 Twinkle이 맡습니다.

```
  Core/Options.lua       설정 창 (모듈의 옵션 선언으로 자동 생성)

```

테스트는 실제 애드온 코드를 Lua 5.1 런타임에서 모의 WoW API 위에 올려 실행합니다. 동작 테스트 외에도 TOC의 파일이 모두 있는지, 애드온이 읽는 전역 이름이 모두 알려진 WoW API인지(오타 방지), 등록하는 이벤트가 모두 실제 이벤트인지, 코드에서 쓰는 문자열이 한국어 · 영어 모두 있는지 확인합니다.

```bash
pip install lupa
```

```bash
python3 tests/run_bigarms_tests.py
```

새 모듈은 `ns:NewModule("이름", { group = ..., defaults = {...}, options = {...} })` 로 선언하고 `OnEnable` / `OnDisable` 을 정의한 뒤 TOC에 파일을 추가하면 설정 창과 `/ba` 명령에 자동으로 나타납니다. 문자열은 `Core/Locale.lua` 에 `MOD_이름`, `MOD_이름_DESC` 와 옵션 라벨을 영어 · 한국어로 넣습니다.
